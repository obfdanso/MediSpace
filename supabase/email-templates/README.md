# MediSpace email templates

Paste each file into Supabase → Authentication → Emails → Templates (switch the editor to "Source" first).

| Supabase template | Subject | File |
|---|---|---|
| Confirm signup | Confirm your MediSpace account | `confirm-signup.html` |
| Reset password | Reset your MediSpace password | `reset-password.html` |
| Change email address | Confirm your new MediSpace email | `change-email.html` |
| Magic link | Your MediSpace sign-in link | `magic-link.html` |
